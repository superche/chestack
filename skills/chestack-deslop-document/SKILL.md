# CheStack Deslop Document

1. Read the [host contract](../chestack/references/hosts.md). Identify the target text, reader, source facts, requested language/standard, and whether the request authorizes edits or findings only. Preserve unrelated work.
2. Read [Writing](../chestack/references/writing.md) and the relevant document-type or engineering-artifact guide. Retain the artifact's purpose; an explanation is not automatically rewritten as a procedure.
3. Execute the [revision workflow](../chestack/references/writing/revision.md) and its full applicable checklist. Check meaning and evidence before style. Preserve conditions, negations, quantities, identifiers, and meaningful uncertainty. Mark missing facts rather than inventing a smoother account.
4. If editing is authorized, remove filler and ambiguity with focused revisions. Keep authoritative legal/safety wording and user-required format. Review-only requests return located findings and proposed corrections without changing the source.
5. Recheck corrected claims and the relevant executable examples. Resolve blocking/major findings or return the precise unresolved gap. Distinguish self-review, independent review, command execution, and formal standard checks.

**Return:** the revised artifact or actionable review findings, with material verification limits. Keep the review record outside the artifact unless requested. This skill does not change code behavior or authorize publishing.

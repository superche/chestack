# chestack-review

Read [host capabilities](../chestack/references/hosts.md) and the [review guide](../chestack/references/review.md). Resolve the exact base and head or artifact. Trace callers outside the diff and verify concrete failure paths. Report actionable findings with severity, file locations, and evidence; state residual coverage when no findings remain. Use independent reviewers only under the [delegation contract](../chestack/references/delegation.md).

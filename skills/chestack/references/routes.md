# Workflow routes

Choose one primary skill or playbook from the requested outcome. Read its full file. A follow-up can switch routes; a status question does not cancel active work.

| Request | Skill or playbook |
|---|---|
| Trace how current code or a subsystem works | [How](../../chestack-how/SKILL.md) |
| Explain why a design or behavior was chosen | [Why](../../chestack-why/SKILL.md) |
| Teach a concept, subsystem, or change | [Teach](../../chestack-teach/SKILL.md) |
| Reconstruct context across prior work and live state | [Recall](../../chestack-recall/SKILL.md) |
| Choose a direction through investigation or a demo | [Explore](../../chestack-explore/SKILL.md) |
| Design caller interfaces, types, ownership, or state transitions | [Architect](../../chestack-architect/SKILL.md) |
| Compare candidates and synthesize a verified artifact | [Arena](../../chestack-arena/SKILL.md) |
| Another read-only question about design or risk | [investigation](playbooks/investigation.md) |
| New or changed behavior | [feature](playbooks/feature.md) |
| An observed defect | [bug-fix](playbooks/bug-fix.md) |
| Structure changes while behavior stays stable | [refactoring](playbooks/refactoring.md) |
| An observed latency, throughput, CPU, or memory regression | [perf-issue](playbooks/perf-issue.md) |
| Repeated optimization toward a measured target | [hillclimb](playbooks/hillclimb.md) |
| A live resource leak, spin, hang, or intermittent failure | [runtime-forensics](playbooks/runtime-forensics.md) |
| A supplied trace, profile, heap, or log artifact | [trace-forensics](playbooks/trace-forensics.md) |
| A specific empirical question for a throwaway experiment | [prototype](playbooks/prototype.md) |
| Match a reference UI or interaction | [visual-parity](playbooks/visual-parity.md) |
| Prepare a reviewable GitHub change | [opening-a-pr](playbooks/opening-a-pr.md) |
| Check or drive a PR toward merge readiness | [babysit](playbooks/babysit.md) |
| The user explicitly requests merge or release | [shipping](playbooks/shipping.md) |
| Several independently owned PR lifecycles | [autopilot-full](playbooks/autopilot-full.md) |
| A root owner manages an ordered stack | [autopilot-stack](playbooks/autopilot-stack.md) |
| A multi-track program outlives one worker session | [orchestrate](playbooks/orchestrate.md) |
| The user authorizes a bounded unattended run | [autonomous-run](playbooks/autonomous-run.md) |
| The user asks to stop or pause | [pause-safely](playbooks/pause-safely.md) |
| Resume existing work | [session-pickup](playbooks/session-pickup.md) |
| A requested plan spanning phases or PRs | [multi-phase-plan](playbooks/multi-phase-plan.md) |
| Create or modify reusable agent guidance | [authoring-a-skill](playbooks/authoring-a-skill.md) |
| Evaluate an agent workflow or artifact | [eval](playbooks/eval.md) |
| Inspect or clean development worktrees | [worktree-cleanup](playbooks/worktree-cleanup.md) |

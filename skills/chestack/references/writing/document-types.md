# Select the document type

Use [Diátaxis](https://diataxis.fr/start-here/) to distinguish the reader's purpose. Read only the matching file; each owns its standard, writing procedure, completion condition, and complete worked example.

| Reader need | Type and guide | Governing basis |
|---|---|---|
| Learn by producing a first result | [Tutorial](tutorial.md) | Diátaxis tutorials |
| Complete a known task | [How-to](how-to.md) | Diátaxis how-to structure and ASD-STE100 procedure language |
| Look up an exact contract | [Reference](reference.md) | Diátaxis reference and the actual interface specification |
| Understand mechanisms and tradeoffs | [Explanation](explanation.md) | Diátaxis explanation and source-backed reasoning |

For mixed requests, separate purposes into clearly navigable sections or linked pages. Do not make a tutorial carry a full reference table or bury task steps inside rationale. Follow a supplied format when it serves the requested result; the types are not mandatory templates.

For standard selection or conformance claims, read [standards](standards.md). For PRs, RFCs, decision records, and commit messages, use [engineering artifacts](engineering-artifacts.md).

# Delegation contract

Check that the host exposes subagents and that the current instructions allow using them. A general CheStack task is not permission to bypass a host rule requiring explicit delegation approval. Without that capability or authorization, execute the same scoped work sequentially.

Give each worker the goal, acceptance criteria, source pointers, write boundary, exclusive branch or worktree, relevant user constraints, budget, and expected report. Transfer task evidence rather than private unrelated conversation history. Inherit the current model unless the user specifies a supported alternative.

Choose a shape that earns its coordination cost:

- **Coverage:** partition by feature, subsystem, source category, or failure class; track covered and missing cells.
- **Candidates:** separate competing implementations, then evaluate under the same conditions.
- **Independent review:** a separate reviewer inspects the artifact without being told the desired verdict.

Keep shared state under one owner. Return file or commit pointers, executed checks, results, and uncertainties. The parent validates material claims, resolves conflicting findings, and synthesizes the final answer. A report is a pointer to evidence, not evidence by itself.

Use bounded waits and respond to user steering. Stop starting work at a pause request, preserve partial artifacts, and avoid unmanaged background processes. A Markdown role description does not register a named runtime agent. Use only actual host agent identifiers and schemas.

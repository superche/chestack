# prototype

**Use for:** A factual design uncertainty.

Read [host capabilities](../hosts.md) and the relevant [principles](../principles.md) before acting.

1. Name the uncertainty and the observation that selects an approach.
2. Build the smallest throwaway experiment that exposes it; isolate it from production code.
3. Compare materially different candidates on identical criteria and retain their evidence.
4. Recommend a direction and state which prototype assumptions still need production validation.

**Principles:** [exhaust-the-design-space](../principles/exhaust-the-design-space.md), [experience-first](../principles/experience-first.md).

**Done:** The experiment answers the named uncertainty; a prototype is not reported as production-ready.

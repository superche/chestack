# visual-parity

**Use for:** Match a reference UI or interaction.

Read [host capabilities](../hosts.md) and the relevant [principles](../principles.md) before acting.

1. Record the reference viewport, state, content, and interaction boundaries.
2. Capture the target application window or browser and verify its identity before comparing.
3. Migrate one component at a time and compare matching states, including loading and errors.
4. Review screenshots and interaction evidence against the requested boundary; request review only where the user made it a gate.

**Principles:** [experience-first](../principles/experience-first.md), [prove-it-works](../principles/prove-it-works.md), [sequence-verifiable-units](../principles/sequence-verifiable-units.md).

**Done:** Matching-state visual and interaction evidence exists for the real target surface.

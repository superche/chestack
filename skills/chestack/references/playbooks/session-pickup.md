# session-pickup

**Use for:** Resume existing work.

Read [host capabilities](../hosts.md) and the relevant [principles](../principles.md) before acting.

1. Read the user-provided or current-task checkpoint and authorized history; keep unrelated private histories out of scope.
2. Inspect live branches, status, processes, PR heads, and checks before trusting old completion claims.
3. Reconcile changed instructions and stale assumptions; restore the acceptance condition and next safe unit.
4. Resume within current authorization and report any material mismatch.

**Principles:** [prove-it-works](../principles/prove-it-works.md), [guard-the-context-window](../principles/guard-the-context-window.md).

**Done:** The resumed plan is grounded in live state rather than inherited self-report.
